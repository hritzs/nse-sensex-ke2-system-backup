Local feed and peer failover

Each PC publishes its own native feed. This application uses local data first and verified peers if a stream becomes stale. NSE, BSE derivatives and BSE indices select sources independently.

Live data requires exchange multicast access or a reachable, matching native peer. Bundled reference data is a dated snapshot. Configure authoritative input_sources for daily refresh.

Add peers as {"name":"desk-b","raw_url":"ws://192.168.1.22:19001/ke2-source"}. The peer must run this standalone native publisher with matching masters. List peers in priority order. Set interface to the PC's feed-facing IPv4 address when needed.
